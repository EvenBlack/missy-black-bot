# Локальний редактор

Редактор використовує Pillow у процесі бота, без Groq, Cloudflare AI або OpenAI API. AI-квота на обробку не витрачається. Завантаження, Telegram, CPU Render та запис у Drive підпорядковані звичайним лімітам відповідних сервісів.

Відповісти на зображення чи файл-зображення:

- `/edit світліше`
- `/edit темніше`
- `/edit тепліше`
- `/edit холодніше`
- `/edit контраст 1.2`
- `/edit яскравість 1.15`
- `/edit обрізати 1:1` або `/edit обрізати 16:9` — обрізання по центру.
- `/edit напис Привіт, Україно!` — білий напис на затемненій смузі внизу фото.

`/edit себе світліше` бере основний образ Катрусі. `/edit КОД_ФОТО тепліше` бере файл із власного архіву користувача. Для кількох змін відповідати наступною командою на отриманий результат.

Оригінал і основний образ не замінюються. Змінений файл надсилається документом і, якщо доступний Drive, зберігається як окрема архівна копія. Повторний запис ідентичних вихідним байтів пропускається, щоб не змінювати підпис оригінального запису. Якщо архів недоступний, готовий результат усе одно надсилається з чесним повідомленням про незбереження.

Обмеження першої версії: до 8 МіБ на вхід і вихід, до 16 млн пікселів на вхід; довша сторона робочої копії — до 3072 пікселів з повідомленням про зменшення. Оригінальні байти не переписуються. Вихід PNG, за потреби для непрозорого великого результату — JPEG. Анімовані й багатосторінкові зображення відхиляються без тихого перетворення лише першого кадру. Для написів установлюється DejaVu Sans із підтримкою української. Додавання предметів, заміна фону й генеративні зміни сюди не входять.

Google Apps Script та наявні ключі оновлювати не потрібно.
